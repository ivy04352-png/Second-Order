    Second post · English / 中文

    In 1990, AT&T built a backup processor specifically so a failure in one wouldn't take a switch offline. It didn't help — the backup ran the identical buggy software, in the identical vulnerable state, waiting for the identical trigger. A single misplaced line of code cascaded across 114 switches and killed half the nation's long-distance calls for nine hours. What that says about redundancy built from identical clones.
